# Two-step equations

<!-- la:orientation -->
We learn to solve equations such as 3x + 5 = 20.

<!-- la:outcomes -->
By the end you will be able to:

1. Undo an addition or subtraction on both sides.
2. Undo a multiplication on both sides.
3. Check a solution by substitution.

<!-- la:misconception -->
> A tempting mistake: dividing before subtracting. It gives a fraction mess; undo the outer operation first.

<!-- la:exercise id=E2 outcomes=1,2 level=independent -->
**Exercise 2.** Solve 4x - 3 = 13.

<!-- la:worked-example -->
## Worked example

3x + 5 = 20, subtract 5, divide by 3, x = 5.

<!-- la:solution id=E1 -->
**Solution.** x = 4.
